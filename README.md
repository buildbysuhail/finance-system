# Finance Management System (Frontend Only)

## 📌 Project Overview

This is a Finance Management System built as part of a 5-day evaluation task.  
The application allows users to manage financial transactions, categorize income and expenses, and visualize reports using charts.

The backend is simulated using MockAPI.io.

---

## 🎯 Objectives

- Demonstrate structured frontend architecture
- Implement clean and reusable components
- Apply strong TypeScript typing
- Use proper state management
- Follow professional documentation standards
- Ensure maintainability and scalability

---

## 🛠 Tech Stack

- React (Vite)
- TypeScript
- TailwindCSS
- React Router
- Axios
- React Hook Form
- Recharts
- Context API
- MockAPI.io (REST API)

---

## 🚀 Features

- Mock Authentication
- Dashboard with financial summary
- Transactions CRUD
- Categories CRUD
- Financial Reports (Charts)
- Profile / Settings Page
- Form validation
- Loading & error handling
- Responsive UI
